# File Organizer

**File Organizer** — це консольний застосунок (CLI), створений на Node.js для аналізу, організації та очищення файлів у директоріях.

Застосунок дозволяє рекурсивно сканувати директорії, знаходити дублікати файлів за допомогою SHA-256 хешів, сортувати файли за категоріями, а також знаходити та видаляти застарілі файли.

## Можливості

- Рекурсивне сканування директорій
- Підрахунок кількості та загального розміру файлів
- Групування файлів за розширенням
- Аналіз файлів за віком
- Пошук трьох найбільших файлів
- Визначення найстарішого файлу
- Пошук дублікатів за допомогою SHA-256
- Підрахунок місця, зайнятого дублікатами
- Сортування файлів за категоріями
- Обробка конфліктів однакових назв файлів
- Використання streams для великих файлів
- Пошук старих файлів у режимі dry run
- Видалення старих файлів за допомогою прапорця `--confirm`
- Відстеження операцій за допомогою EventEmitter

## Вимоги

- Node.js 22 або новіша версія
- npm

## Встановлення

Клонуйте репозиторій та відкрийте директорію проєкту.

Встановіть залежності:

```bash
npm install
```

Проєкт не потребує додаткових зовнішніх пакетів.

## Використання

Застосунок підтримує чотири основні команди:

- `scan`
- `duplicates`
- `organize`
- `cleanup`

Команди можна запускати за допомогою npm scripts.

### Scan

Команда `scan` рекурсивно сканує вказану директорію та показує статистику про знайдені файли.

```bash
npm run scan -- ./path-to-directory
```

Звіт містить:

- загальну кількість файлів;
- загальний розмір файлів;
- групування файлів за розширенням;
- кількість файлів, змінених за останні 7 днів;
- кількість файлів, змінених за останні 30 днів;
- кількість файлів, старіших за 90 днів;
- три найбільші файли;
- найстаріший файл.

### Duplicates

Команда `duplicates` шукає файли з однаковим вмістом за допомогою SHA-256 хешів.

```bash
npm run duplicates -- ./path-to-directory
```

Для обчислення хешів використовується `fs.createReadStream()`, тому файл читається частинами і не завантажується повністю в оперативну пам'ять.

У результаті команда показує групи дублікатів, шляхи до файлів, SHA-256 хеші та кількість дискового простору, зайнятого зайвими копіями.

### Organize

Команда `organize` копіює файли з вихідної директорії до цільової та сортує їх за категоріями.

```bash
npm run organize -- ./source-directory --output ./target-directory
```

Аргумент `--output` визначає директорію, до якої будуть скопійовані організовані файли.

Файли розподіляються за категоріями:

- `Documents`
- `Images`
- `Archives`
- `Code`
- `Videos`
- `Other`

Оригінальні файли залишаються у вихідній директорії та не видаляються.

Файли розміром менше 10 MB копіюються за допомогою `fs.copyFile()`. Для файлів розміром 10 MB і більше використовуються streams та `pipeline()`.

Якщо файл з таким самим ім'ям уже існує в цільовій директорії, він не перезаписується. До його назви додається порядковий номер:

```text
file.pdf
file(1).pdf
file(2).pdf
```

Після завершення команда показує кількість скопійованих файлів у кожній категорії та їх загальний розмір.

### Cleanup

Команда `cleanup` знаходить файли, старіші за вказану кількість днів.

Для безпечного перегляду файлів без їх видалення використовується dry run:

```bash
npm run cleanup -- ./path-to-directory --older-than 90
```

Аргумент `--older-than` визначає мінімальний вік файлу в днях.

Без прапорця `--confirm` команда лише показує знайдені файли та **не видаляє їх**.

Для фактичного видалення використовується:

```bash
npm run cleanup -- ./path-to-directory --older-than 90 --confirm
```

Прапорець `--confirm` дозволяє видалити знайдені файли.

### Опис файлів

- `file-organizer.js` — точка входу в застосунок та обробка аргументів командного рядка.
- `lib/scanner.js` — рекурсивне сканування директорій та збір статистики.
- `lib/duplicates.js` — пошук дублікатів за допомогою SHA-256.
- `lib/organizer.js` — сортування та копіювання файлів.
- `lib/cleanup.js` — пошук і видалення застарілих файлів.

## EventEmitter

Кожна команда реалізована як окремий клас, який наслідується від `EventEmitter`.

Події використовуються для відокремлення бізнес-логіки роботи з файлами від виведення інформації в консоль та дозволяють відстежувати процес виконання операцій.

Основні події:

- `Scanner`: `scan-start`, `file-found`, `scan-complete`
- `DuplicateFinder`: `file-processed`, `duplicates-found`
- `Organizer`: `copy-start`, `copy-complete`, `copy-error`
- `Cleanup`: `file-found`, `file-deleted`, `cleanup-complete`

## Обробка помилок

Операції з файловою системою обробляються за допомогою `try...catch`.

Застосунок обробляє, зокрема, такі помилки:

- `ENOENT` — директорія або файл не існує;
- `EACCES` — відсутній дозвіл на доступ;
- інші непередбачені помилки файлової системи.
